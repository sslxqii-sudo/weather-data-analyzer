# 🌦️ Weather Data Analyzer

A colorful and interactive weather dashboard built using **Python, Pandas, Matplotlib, and Streamlit**.

## ✨ Features

* 🌡️ Average, maximum & minimum temperature
* 🌧️ Rainfall analysis
* 💧 Humidity analysis
* 📈 Temperature and rainfall graphs
* 📅 Date-based filtering
* 📁 Upload your own CSV dataset
* 📥 Download filtered data
* 🎨 Interactive and colorful dashboard

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Matplotlib
* Git & GitHub
